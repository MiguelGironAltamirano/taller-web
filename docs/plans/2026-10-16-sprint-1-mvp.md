# Sprint 1 — MVP: plan maestro de implementación

> **Ejecución:** la Fase A es secuencial y está detallada paso a paso en este documento. Las fases B y C corren en paralelo, cada flujo en su propio git worktree y rama; su plan detallado (con código) se escribe al iniciar la fase, sobre los contratos ya integrados de la Fase A. Pasos con checkbox (`- [ ]`). Seguimiento: `odd/tasks/sprint-1-mvp.md`.

**Objetivo:** entregar para la semana 10 un MVP de punta a punta: registro e inicio de sesión, registro de solicitudes, consulta según rol y ciclo de estados con asignación e historial.

**Arquitectura:** monolito modular Spring Boot (módulos `auth`, `catalog`, `requests`, `workflow` con capas `domain` / `application` / `infrastructure`) y SPA React que consume `/api/v1`. La Fase A fija tres contratos (esquema de base de datos, seguridad JWT y API) para que backend, frontend y documentación avancen en paralelo sin bloquearse.

**Stack:** Java 25 · Spring Boot 4.1.1 · Spring Security (OAuth2 Resource Server, JWT HS256) · Spring Data JPA · MySQL 8.4 · Flyway · Testcontainers · React 19 · TypeScript · TanStack Query · React Router · React Hook Form + Zod · MSW · Vitest.

**Spec:** `docs/specs/2026-10-14-servicios-universitarios-design.md` (secciones 3.4, 4, 5, 6, 7 y 8).

**Prerrequisito:** Sprint 0 completo en `feature/sprint-0-base` (esta rama parte de su último commit, `4bbebdf`).

## Restricciones globales

- Java 25, Spring Boot 4.1.1, MySQL 8.4; API bajo `/api/v1`; errores RFC 7807 (`application/problem+json`).
- JWT: token de acceso de 15 minutos; token de renovación de 7 días con rotación, en cookie `HttpOnly`, `Secure`, `SameSite=Strict`, `Path=/api/v1/auth`.
- Contraseñas con BCrypt. El secreto JWT llega por la variable `APP_JWT_SECRET` (mínimo 32 bytes); nunca se versiona un secreto real.
- El autorregistro solo crea cuentas `SOLICITANTE` y exige correo `@unmsm.edu.pe`.
- Código de solicitud `SOL-AAAA-NNNNNN`, correlativo por año, único e inmutable.
- Descripción de la solicitud: 20 a 2000 caracteres. Vencimiento = fecha de registro + horas de SLA de la prioridad.
- Estados: `REGISTRADA`, `EN_EVALUACION`, `ASIGNADA`, `EN_ATENCION`, `RESUELTA`, `CERRADA`; las transiciones son exactamente las de la sección 6 del spec. Una transición no permitida responde `409`.
- Fechas en UTC (`DATETIME(6)` en MySQL; `Instant` en Java; ISO-8601 en JSON).
- Textos de la interfaz en español; TypeScript estricto.
- Los usuarios de demostración solo existen en entornos de desarrollo y staging (ubicación Flyway `db/seed-dev`), nunca en producción.

## Foco de revisión

1. **Token ausente, vencido o alterado:** la API responde `401` con `application/problem+json`; el frontend intenta una renovación y, si falla, vuelve al login → pruebas en Task A2 y en el flujo B2.
2. **Un solicitante pide por código una solicitud ajena:** responde `404`, sin revelar que existe → prueba obligatoria en el flujo C1.
3. **Dos solicitudes creadas al mismo tiempo:** reciben códigos distintos y consecutivos → prueba concurrente obligatoria en el flujo C1.
4. **Transición inválida** (por ejemplo `REGISTRADA → RESUELTA`, o un técnico que no es el asignado): `409` o `403`, sin modificar la solicitud → pruebas obligatorias en el flujo C1.
5. **Registro con correo ajeno a UNMSM o ya registrado:** `400` o `409` con el campo señalado; la contraseña nunca se guarda en claro → pruebas obligatorias en el flujo B1 y verificación en Task A1.

CREATE TABLE areas (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  active BOOLEAN NOT NULL DEFAULT TRUE,
  CONSTRAINT uk_areas_name UNIQUE (name)
);

CREATE TABLE categories (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  default_area_id BIGINT NOT NULL,
  active BOOLEAN NOT NULL DEFAULT TRUE,
  CONSTRAINT uk_categories_name UNIQUE (name),
  CONSTRAINT fk_categories_area FOREIGN KEY (default_area_id) REFERENCES areas (id)
);

CREATE TABLE priorities (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(50) NOT NULL,
  sla_hours INT NOT NULL,
  sort_order INT NOT NULL,
  CONSTRAINT uk_priorities_name UNIQUE (name),
  CONSTRAINT ck_priorities_sla CHECK (sla_hours > 0)
);

CREATE TABLE locations (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(150) NOT NULL,
  kind VARCHAR(20) NOT NULL,
  parent_id BIGINT NULL,
  CONSTRAINT fk_locations_parent FOREIGN KEY (parent_id) REFERENCES locations (id),
  CONSTRAINT ck_locations_kind CHECK (kind IN ('FACULTAD', 'PABELLON', 'AMBIENTE'))
);

CREATE TABLE users (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  full_name VARCHAR(150) NOT NULL,
  email VARCHAR(150) NOT NULL,
  password_hash VARCHAR(100) NOT NULL,
  role VARCHAR(20) NOT NULL,
  requester_type VARCHAR(20) NULL,
  area_id BIGINT NULL,
  active BOOLEAN NOT NULL DEFAULT TRUE,
  created_at DATETIME(6) NOT NULL,
  CONSTRAINT uk_users_email UNIQUE (email),
  CONSTRAINT fk_users_area FOREIGN KEY (area_id) REFERENCES areas (id),
  CONSTRAINT ck_users_role CHECK (role IN ('SOLICITANTE', 'TECNICO', 'SUPERVISOR', 'ADMINISTRADOR')),
  CONSTRAINT ck_users_requester_type CHECK (requester_type IS NULL OR requester_type IN ('ESTUDIANTE', 'DOCENTE', 'ADMINISTRATIVO'))
);

CREATE TABLE refresh_tokens (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  user_id BIGINT NOT NULL,
  token_hash CHAR(64) NOT NULL,
  expires_at DATETIME(6) NOT NULL,
  revoked_at DATETIME(6) NULL,
  created_at DATETIME(6) NOT NULL,
  CONSTRAINT uk_refresh_tokens_hash UNIQUE (token_hash),
  CONSTRAINT fk_refresh_tokens_user FOREIGN KEY (user_id) REFERENCES users (id)
);

CREATE TABLE request_code_sequences (
  seq_year INT PRIMARY KEY,
  last_value INT NOT NULL
);

CREATE TABLE service_requests (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  code VARCHAR(20) NOT NULL,
  requester_id BIGINT NOT NULL,
  category_id BIGINT NOT NULL,
  location_id BIGINT NOT NULL,
  description VARCHAR(2000) NOT NULL,
  priority_id BIGINT NOT NULL,
  status VARCHAR(20) NOT NULL,
  area_id BIGINT NOT NULL,
  technician_id BIGINT NULL,
  closure_reason VARCHAR(20) NULL,
  created_at DATETIME(6) NOT NULL,
  due_at DATETIME(6) NOT NULL,
  updated_at DATETIME(6) NOT NULL,
  version BIGINT NOT NULL DEFAULT 0,
  CONSTRAINT uk_service_requests_code UNIQUE (code),
  CONSTRAINT fk_service_requests_requester FOREIGN KEY (requester_id) REFERENCES users (id),
  CONSTRAINT fk_service_requests_category FOREIGN KEY (category_id) REFERENCES categories (id),
  CONSTRAINT fk_service_requests_location FOREIGN KEY (location_id) REFERENCES locations (id),
  CONSTRAINT fk_service_requests_priority FOREIGN KEY (priority_id) REFERENCES priorities (id),
  CONSTRAINT fk_service_requests_area FOREIGN KEY (area_id) REFERENCES areas (id),
  CONSTRAINT fk_service_requests_technician FOREIGN KEY (technician_id) REFERENCES users (id),
  CONSTRAINT ck_service_requests_status CHECK (status IN ('REGISTRADA', 'EN_EVALUACION', 'ASIGNADA', 'EN_ATENCION', 'RESUELTA', 'CERRADA')),
  CONSTRAINT ck_service_requests_closure CHECK (closure_reason IS NULL OR closure_reason IN ('NO_PROCEDE', 'DUPLICADA', 'CONFIRMADA'))
);

CREATE INDEX ix_service_requests_requester ON service_requests (requester_id);
CREATE INDEX ix_service_requests_area_status ON service_requests (area_id, status);
CREATE INDEX ix_service_requests_technician_status ON service_requests (technician_id, status);

CREATE TABLE request_history (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  request_id BIGINT NOT NULL,
  from_status VARCHAR(20) NULL,
  to_status VARCHAR(20) NOT NULL,
  actor_id BIGINT NOT NULL,
  technician_id BIGINT NULL,
  reason VARCHAR(500) NULL,
  created_at DATETIME(6) NOT NULL,
  CONSTRAINT fk_request_history_request FOREIGN KEY (request_id) REFERENCES service_requests (id),
  CONSTRAINT fk_request_history_actor FOREIGN KEY (actor_id) REFERENCES users (id),
  CONSTRAINT fk_request_history_technician FOREIGN KEY (technician_id) REFERENCES users (id)
);

CREATE INDEX ix_request_history_request ON request_history (request_id, created_at);

package pe.edu.unmsm.servicios.shared.infrastructure.security;

import java.time.Instant;
import java.util.List;

import org.springframework.security.oauth2.jose.jws.MacAlgorithm;
import org.springframework.security.oauth2.jwt.JwsHeader;
import org.springframework.security.oauth2.jwt.JwtClaimsSet;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtEncoderParameters;
import org.springframework.stereotype.Component;

import pe.edu.unmsm.servicios.shared.domain.AuthenticatedUser;

@Component
public class AccessTokenIssuer {

	public record IssuedToken(String value, long expiresInSeconds) {
	}

	private final JwtEncoder encoder;
	private final JwtProperties properties;

	AccessTokenIssuer(JwtEncoder encoder, JwtProperties properties) {
		this.encoder = encoder;
		this.properties = properties;
	}

	public IssuedToken issue(AuthenticatedUser user) {
		Instant now = Instant.now();
		JwtClaimsSet claims = JwtClaimsSet.builder()
				.issuer(properties.issuer())
				.subject(Long.toString(user.id()))
				.issuedAt(now)
				.expiresAt(now.plus(properties.accessTokenTtl()))
				.claim("email", user.email())
				.claim("name", user.fullName())
				.claim("roles", List.of(user.role()))
				.build();
		JwsHeader header = JwsHeader.with(MacAlgorithm.HS256).build();
		String value = encoder.encode(JwtEncoderParameters.from(header, claims)).getTokenValue();
		return new IssuedToken(value, properties.accessTokenTtl().toSeconds());
	}

}

import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.method.configuration.EnableMethodSecurity;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;

import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;
import org.springframework.security.crypto.password.PasswordEncoder;

import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.NimbusJwtDecoder;
import org.springframework.security.oauth2.jwt.NimbusJwtEncoder;
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationConverter;
import org.springframework.security.oauth2.server.resource.authentication.JwtGrantedAuthoritiesConverter;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableMethodSecurity
@EnableConfigurationProperties(JwtProperties.class)
class SecurityConfig {

	private static final String[] PUBLIC_PATHS = { "/api/v1/auth/**", "/api/v1/system/**", "/v3/api-docs/**",
			"/swagger-ui/**", "/swagger-ui.html", "/actuator/health/**", "/error" };

	@Bean
	SecurityFilterChain apiSecurity(HttpSecurity http, ProblemDetailsSecurityHandler problems) throws Exception {
		return http
				.csrf(csrf -> csrf.disable())
				.sessionManagement(session -> session.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
				.authorizeHttpRequests(auth -> auth.requestMatchers(PUBLIC_PATHS).permitAll().anyRequest().authenticated())
				.oauth2ResourceServer(oauth -> oauth
						.jwt(jwt -> jwt.jwtAuthenticationConverter(jwtAuthenticationConverter()))
						.authenticationEntryPoint(problems)
						.accessDeniedHandler(problems))
				.exceptionHandling(errors -> errors.authenticationEntryPoint(problems).accessDeniedHandler(problems))
				.build();
	}

	@Bean
	SecretKey jwtSecretKey(JwtProperties properties) {
		byte[] bytes = properties.secret() == null ? new byte[0] : properties.secret().getBytes(StandardCharsets.UTF_8);
		if (bytes.length < 32) {
			throw new IllegalStateException("app.jwt.secret must be at least 32 bytes");
		}
		return new SecretKeySpec(bytes, "HmacSHA256");
	}

	@Bean
	JwtDecoder jwtDecoder(SecretKey jwtSecretKey) {
		return NimbusJwtDecoder.withSecretKey(jwtSecretKey).macAlgorithm(MacAlgorithm.HS256).build();
	}

	@Bean
	JwtEncoder jwtEncoder(SecretKey jwtSecretKey) {
		return new NimbusJwtEncoder(new ImmutableSecret<>(jwtSecretKey));
	}

	@Bean
	PasswordEncoder passwordEncoder() {
		return new BCryptPasswordEncoder();
	}

	private JwtAuthenticationConverter jwtAuthenticationConverter() {
		JwtGrantedAuthoritiesConverter authorities = new JwtGrantedAuthoritiesConverter();
		authorities.setAuthoritiesClaimName("roles");
		authorities.setAuthorityPrefix("ROLE_");
		JwtAuthenticationConverter converter = new JwtAuthenticationConverter();
		converter.setJwtGrantedAuthoritiesConverter(authorities);
		return converter;
	}

}

# Contrato de API del MVP (v1)

Base: `/api/v1`. JSON en UTF-8. Fechas ISO-8601 en UTC. Errores: `application/problem+json` con `type`, `title`, `status`, `detail` y, en validación, `errors: { campo: mensaje }`.

## Autenticación

| Método y ruta | Acceso | Cuerpo | Respuesta |
|---|---|---|---|
| `POST /auth/register` | Público | `{ fullName, email, password, requesterType }` | `201` `UserSummary` · `400` validación · `409` correo ya registrado |
| `POST /auth/login` | Público | `{ email, password }` | `200` `TokenResponse` + cookie `refresh_token` · `401` credenciales inválidas |
| `POST /auth/refresh` | Cookie `refresh_token` | — | `200` `TokenResponse` + cookie rotada · `401` |
| `POST /auth/logout` | Cookie `refresh_token` | — | `204`, cookie eliminada y token revocado |
| `GET /me` | Token | — | `200` `{ id, email, fullName, role }` |

Reglas de registro: `email` termina en `@unmsm.edu.pe`; `password` de 8 a 72 caracteres con al menos una letra y un dígito; `requesterType` ∈ `ESTUDIANTE`, `DOCENTE`, `ADMINISTRATIVO`; `fullName` de 3 a 150 caracteres.

|---|---|---|
| `GET /catalogs` | Token | `200` `Catalogs` |

| Método y ruta | Acceso | Cuerpo | Respuesta |
|---|---|---|---|
| `POST /requests` | Rol `SOLICITANTE` | `{ categoryId, locationId, description, priorityId }` | `201` `RequestDetail` · `400` |
| `GET /requests?status=&page=0&size=20` | Token | — | `200` `Page<RequestSummary>` filtrado por rol |

function problem(status: number, title: string, detail: string) {
  return HttpResponse.json({ type: 'about:blank', title, status, detail }, {
    status,
    headers: { 'Content-Type': 'application/problem+json' },
  })
}

function allowedTransitions(request: StoredRequest, user: UserSummary): RequestStatus[] {
  const supervisorOfArea = user.role === 'SUPERVISOR' && user.areaId === request.areaId
  const assignedTechnician = user.role === 'TECNICO' && user.id === request.technicianId
  const owner = user.role === 'SOLICITANTE' && user.id === request.requesterId
  switch (request.status) {
    case 'REGISTRADA':
      return supervisorOfArea ? ['EN_EVALUACION', 'CERRADA'] : []
    case 'EN_EVALUACION':
      return supervisorOfArea ? ['ASIGNADA', 'CERRADA'] : []
    case 'ASIGNADA':
      return supervisorOfArea ? ['ASIGNADA'] : assignedTechnician ? ['EN_ATENCION'] : []
    case 'EN_ATENCION':
      return assignedTechnician ? ['RESUELTA'] : []
    case 'RESUELTA':
      return owner ? ['CERRADA', 'EN_ATENCION'] : []
    default:
      return []
  }
}

function visible(request: StoredRequest, user: UserSummary): boolean {
  if (user.role === 'ADMINISTRADOR') return true
  if (user.role === 'SUPERVISOR') return request.areaId === user.areaId
  if (user.role === 'TECNICO') return request.technicianId === user.id
  return request.requesterId === user.id
}

function toDetail(request: StoredRequest, user: UserSummary): RequestDetail {
  return {
    ...toSummary(request),
    description: request.description,
    requester: request.requester,
    area: request.area,
    technician: request.technician,
    closureReason: request.closureReason,
    history: request.history,
    allowedTransitions: allowedTransitions(request, user),
  }
}

    locationName: request.locationName,
    priorityName: request.priorityName,
    status: request.status,

      reason: body.reason ?? null,
      createdAt: new Date().toISOString(),
    })
